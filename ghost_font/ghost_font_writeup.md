# Ghost Font

**Флаг:** `avito{SM4RT3R_TH4N_AI}`

Текст в Ghost Font скрыт в точечном узоре. Для восстановления хватает одного PNG-кадра:
нужные признаки — фаза решётки и совпадение со смещённой копией того же поля.

## Восстановление

Сначала скрипт разбирает PNG: проверяет chunks, CRC и данные после `IEND`. Затем
удаляет рамку браузера и восстанавливает масштаб исходного холста. Произвольное
масштабирование здесь вредно: оно меняет фазу шестипиксельной решётки.

Внутри букв решётка сдвинута по вертикали. Умножение на `exp(-2πi·y/6)` и локальное
усреднение выделяют этот сдвиг, но слегка размывают границы букв.

Второй признак даёт FFT-автокорреляция. Она находит вертикальное смещение `Δy`, при
котором точки внутри букв совпадают со смещённым исходным полем. Карта таких совпадений
сохраняет границы, но содержит шум.

Произведение двух карт оставляет области, подтверждённые обоими способами. После
пороговой обработки и обрезки видны строки:

```text
SM4RT3R
TH4N AI
```

Их запись через подчёркивания даёт содержимое флага.

## Запуск

Нужен исходный `ghost_screenshot.png`; в Git его нет. Зависимости NumPy и Pillow
входят в окружение проекта:

```bash
uv run python ghost_font/decode_ghost.py \
  ghost_font/ghost_screenshot.png -o ghost_font/ghost_decoded.png
```

[decode_ghost.py](decode_ghost.py) выполняет весь разбор и сохраняет восстановленную
маску. Изображения `ghost_decoded.png` и `ghost_coarse.png` создаются при запуске.
