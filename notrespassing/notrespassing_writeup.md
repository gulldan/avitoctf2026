# Не влезай — ужалит (MyOwnCloud)

**Флаг:** `avito{yOuROWnCLoUD_BuT_no7_Your_0wn_fILes}`

MyOwnCloud хранит адрес доставки и ID пользователя для сброса пароля раздельно.
Функция отправки файла меняет тот же адрес в сессии, что и сброс пароля. Поэтому
токен администратора можно отправить на свой почтовый ящик.

## Подмена адреса

После запроса сброса для `admin@cloudbox.local` PHP-сессия содержит:

```text
reset_user_id = ID администратора
contact_email = admin@cloudbox.local
```

`POST /files/share` записывает адрес получателя в `contact_email`, не меняя
`reset_user_id`. Если выполнить его перед `/password/forgot/finalize`, сервер
выпустит токен для администратора, а письмо отправит выбранному получателю.

## Последовательность

1. Зарегистрировать два аккаунта. Второй использует доступный через API ящик mail.tm.
2. Войти первым аккаунтом и загрузить файл, чтобы появился `file_id` для отправки.
3. В той же сессии вызвать `/password/forgot/request` для `admin@cloudbox.local`.
4. Вызвать `/files/share` с этим `file_id` и адресом второго аккаунта.
5. Вызвать `/password/forgot/finalize` и получить из письма 48-символьный hex-токен.
6. Передать токен и новый пароль в `/password/reset`, затем войти администратором.
7. Скачать `/files/download?id=1` — `wiring-diagram.txt` с флагом.

Ограничение на изменение административного аккаунта не применяется к сбросу через
токен, поэтому последний этап проходит.

## Запуск

Нужны работающий MyOwnCloud и доступ к mail.tm:

```bash
uv run python notrespassing/solve_notrespassing.py https://notrespassing-0lcz8q7e.avitoctf.ru
```

[solve_notrespassing.py](solve_notrespassing.py) выполняет всю последовательность.
Локальный MailHog из исходников — отдельный способ получения письма; скрипт использует
внешний ящик. Исходный архив `notrespassing_5e6d73a.zip` в Git не включён.

Адрес сброса нужно брать из записи целевого пользователя, а не из общей изменяемой
переменной сессии. Политика изменения аккаунта должна действовать и при сбросе пароля.
