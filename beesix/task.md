# BI-6 / BeeSix

**Avito CTF 2026 · crypto (netcat, с исходниками)**

## Легенда
БИ-6 — пчелиная секретная служба Королевы (ищет точки нектара и места для ульев). Агенты используют «оригинальное стойкое шифрование», чтобы докладывать в штаб. СМР (медоедская разведка) нашла адрес штаба и перехватила шифрованную переписку агента **0x00B**. 0x00B, возможно, заметил слежку — штаб скоро переедет. Найти место хранения мёда; на серверах штаба может быть полезная инфа.

## Доступ
```
nc beesix-4bkdqxf2.avitoctf.ru 30014
Enter secret: YLABYQidu0G3ihtYKPqk6g
```
Образец секрета: `YLABYQidu0G3ihtYKPqk6g` (22 симв., base62-подобный — как в mayes).

## Исходники (в `beesix/beesix/`)
- `client.py` — клиент агента (как шифрует/что шлёт).
- `server.py` — сервер штаба (как принимает secret, что даёт при доступе).
- `traffic.pcap` — перехваченная переписка 0x00B ↔ штаб.

## Цель
По исходникам понять шифр/протокол, расшифровать перехват (pcap) и/или подделать верный secret, войти на сервер и достать полезную инфу → флаг `avito{...}`.
