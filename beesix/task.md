# BeeSix

БИ-6 передаёт сообщения по собственному зашифрованному протоколу. Даны клиент,
сервер и перехваченный трафик агента 0x00B. Нужно узнать новое место хранения мёда.

Параметры экземпляра во время CTF:

```text
beesix-4bkdqxf2.avitoctf.ru:30014
secret: YLABYQidu0G3ihtYKPqk6g
```

В Git есть `beesix/traffic.pcap`; исходные `client.py` и `server.py` не включены.
