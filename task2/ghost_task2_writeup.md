# Ghost Font — write-up (task2)

**Avito CTF 2026 · категория «Стеганография»**
**Цель:** прочитать послание, скрытое на «шумном» скриншоте. Текст на картинке — флаг.
**Дано:** `ghost_screenshot.png` (~988 КБ) — один кадр из сервиса Ghost Font.

## Флаг

```
avito{SM4RT3R_TH4N_AI}
```

На восстановленной картинке читается **`SM4RT3R`** (верхняя строка) и **`TH4N AI`** (нижняя) → «smarter than AI» лит-спиком (A→4, E→3; финальные «AI» — обычные A и I). Служебный водяной знак «WRITTEN IN GHOST FONT» на этом кадре не проявился ни одним методом — он в отдельном кадре/слое анимации и к флагу не относится.

## Короткий ответ: наложение — часть метода, но не главная

Ghost Font кодирует текст **двумя** способами одновременно, оба привязаны к области букв:

1. **Фаза 6-пиксельной решётки точек** — это основной читаемый сигнал. Всё поле — чёрно-белые точки на сетке `6×6` px. Ячейки фона и ячейки букв отличаются не плотностью и не цветом, а **сдвигом фазы** ячейки. Фазовый детектор (домножение на несущую `exp(-2πi·y/6)` + локальное усреднение) уже даёт разборчивый текст **сам по себе**.
2. **Самоналожение (overlay) сдвинутой копии** — область букв дублирует один и тот же случайный «атлас» точек во второй копии кадра: по X сдвиг `294 px`, по Y — подбирается корреляцией. Совпадение двух копий даёт **резкую, но шумную** карту.

Официальный `decode_ghost.py` **перемножает** обе карты: берёт резкость от наложения только там, где фазовый детектор говорит «здесь буквы». Но чтобы просто прочитать флаг, достаточно и одной фазовой карты (проверено — она читается чисто).

## Почему ИИ видит только шум, а человек — текст

Зацепка в легенде: разведчик прислал **скриншот вместо видео**. Ghost Font — это *анимация* бегущего поля случайных точек. В движении глаз ловит когерентную (одинаково движущуюся / скоррелированную) область и «видит» буквы, а любой отдельный статичный кадр для нейросети/OCR — просто случайный крап. У нас только один кадр, поэтому тот же приём делаем **пространственно**: детектируем фазовую аномалию решётки и/или коррелируем кадр с его сдвинутой копией.

## Ход декодирования (по `decode_ghost.py`)

1. **`inspect_png`** — разбирает PNG по чанкам, проверяет CRC и «хвост» после `IEND`. Вывод: в байтах/метаданных ничего не спрятано — данные чисто **визуальные** (отметает версию «байтики внутри файла»).

2. **`normalize_canvas`** — на скриншоте есть хром браузера. Функция находит границы canvas `1280×720` по плотному полю тёмных точек, вычисляет масштаб скриншота и **пересемплирует обратно в исходное разрешение**, привязываясь к сетке `CELL_SIZE = 6` px.

3. **`carrier_score` — ядро декода.** Бинаризует точки (`пиксель < 100` → «чёрная»), домножает на комплексную несущую `exp(-2πi·y/6)` (период 6 px), вычитает фоновую фазу (посчитанную по рамке кадра) и берёт локальное усреднение (box-mean, радиусы 24 и 9). Там, где фаза ячейки отличается от фоновой, — буквы. **Этой карты уже достаточно, чтобы прочитать `SM4RT3R / TH4N AI`.**

4. **`find_vertical_shift`** — ищет вторую копию случайного атласа (`ATLAS_WIDTH = 1296`): по X сдвиг фиксированный `294 px` (`SIGNAL_X_OFFSET`), по Y — подбирается **круговой корреляцией через FFT** (`argmax`). Это и есть «наложение со сдвигом».

5. **`recover_visual`** — накладывает поле точек на его же копию, сдвинутую на `(Δx = 294, Δy = найденный сдвиг)`, и считает локальное **совпадение** (equality) пиксель-в-пиксель (резко, но шумно). Затем `rendered = clip(exact) * clip(coarse)` — перемножает резкую карту наложения с грубой фазовой из п.3, оставляя чистые буквы.

6. **`save_cropped_visual`** — обрезает по области текста и сохраняет `ghost_decoded.png`.

## Суть в двух строках (интуиция)

> Текст спрятан в **фазе 6-пиксельной решётки точек**: ячейки букв сдвинуты относительно фона. Детектор фазы (несущая `exp(-2πi·y/6)` + локальное усреднение) проявляет буквы; наложение картинки на сдвинутую на ~294 px копию добавляет резкости, но не обязательно для чтения.

## Воспроизведение

```bash
cd task2
python3 decode_ghost.py ghost_screenshot.png -o ghost_decoded.png
# на выходе маска с текстом: SM4RT3R / TH4N AI  ->  avito{SM4RT3R_TH4N_AI}
```

Зависимости: `numpy`, `Pillow` (`pip install numpy pillow`).

## Что сработало, а что нет

- **НЕ работает:** каналы R/G/B, LSB-битовые плоскости, `strings` / `exiftool` / `binwalk` — поле монохромное и случайное, секрета в цвете, младших битах или байтах файла нет.
- **Частично проявляет:** downscale и карты плотности точек — потому что фазовый сдвиг решётки создаёт слабую разницу текстуры на грубом масштабе; текст «проступает», но грязно.
- **Чисто читается:** фазовый детектор 6-px несущей (`carrier_score`); максимально резко — он же в произведении с картой самоналожения атласа.
