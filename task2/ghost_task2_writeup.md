# Ghost Font — райтап

**Флаг:** `avito{SM4RT3R_TH4N_AI}`
**Класс:** Стеганография · **Сложность:** н/д · **Очки:** н/д · **Решило команд:** н/д
**Автор:** н/д (метаданные платформы по этой задаче не сохранены)

**Суть решения в одном абзаце.** Ghost Font прячет текст в единственном «шумном» скриншоте
анимации случайных точек: буквы отличаются от фона не яркостью и не цветом, а **фазой**
6-пиксельной решётки точек плюс вторым, сдвинутым наложением того же самого атласа. Согласованный
фазовый фильтр (несущая `exp(-2πi·y/6)`) и FFT-автокорреляция кадра с самим собой восстанавливают
буквы **без второго кадра** — тем же способом, каким глаз в живой анимации ловит когерентно
движущуюся область на фоне случайного шума.

---

## 1. Задача

Разведчик прислал не видео, а один «шумный» скриншот сервиса **Ghost Font**. На картинке скрыто
послание — это и есть флаг. Нужно прочитать текст, который человек ловит глазом, но OCR/нейросеть
видят как случайный крап.

**Дано:** `ghost_screenshot.png` (~988 КБ) — один кадр анимации Ghost Font (браузерный скриншот
с хромом окна вокруг холста).

## 2. Разведка

**Что видно глазом.** Весь холст — чёрно-белые точки на регулярной сетке. Никакой видимой структуры:
для человека на одном статичном кадре это тоже почти шум, буквы «оживают» только в движении. Значит
секрет — визуальный, но спрятан не в цвете и не в яркости отдельной точки.

**Проверка «а вдруг байтики в файле».** `inspect_png` (в `decode_ghost.py`) разбирает PNG по чанкам,
сверяет CRC каждого и считает «хвост» после `IEND`:

```
Parsed end: 988089; file size: 988089; trailing bytes: 0
```

Все CRC валидны, лишних байт после `IEND` нет.

## 3. Как мы вышли на решение (логика гипотез)

- **Наблюдение.** PNG чист — CRC всех чанков валидны, хвоста после `IEND` нет.
  **Гипотеза** — раз файл не хранит секрет байтово, он спрятан в пикселях.
  **Проверка** — `strings`/`exiftool`/`binwalk` по файлу: ничего. **Отпало**: версия «данные в
  метаданных/после конца файла» закрыта, фокус переносится на изображение.

- **Наблюдение.** Поле монохромное (только чёрные/белые точки).
  **Гипотеза** — секрет может быть в цветовых каналах или младших битах (классическое LSB-стего).
  **Проверка** — раздельный просмотр R/G/B и битовых плоскостей.
  **Тупик**: канал один (монохром), LSB ничего не даёт — там просто нет второго канала для секрета.

- **Наблюдение.** При даунскейле (`ghost_down*.png`) и картах плотности точек (`ghost_density*.png`)
  текст **слабо проступает**, но грязно — читать невозможно.
  **Гипотеза** — раз огрубление масштаба вообще проявляет разницу, значит буквы отличаются от фона
  какой-то **регулярной** характеристикой сетки (типа периодической структуры), а не просто
  «точек больше/меньше». Простое усреднение яркости — слишком грубый инструмент, чтобы её выделить
  чисто.

- **Ключевая зацепка — из легенды.** Прислали **скриншот вместо видео**. Ghost Font — это анимация
  бегущего поля случайных точек; в движении глаз ловит когерентно движущуюся область и «видит» буквы,
  а любой отдельный кадр для OCR — просто крап. У нас один кадр, но тот же приём переносится
  **пространственно**: искать регулярную аномалию сетки и/или коррелировать кадр с его собственной
  сдвинутой копией — вместо согласования по времени (кадр N vs кадр N+1) согласование по
  пространству (пиксель vs его же копия со сдвигом).

- **Гипотеза (фаза решётки).** Если буквы кодируются периодической меткой с периодом сетки
  (`CELL_SIZE = 6` px), то её вытащит **согласованный фильтр** на несущей этого периода —
  `exp(-2πi·y/6)` — а не грубое усреднение.
  **Проверка** — `carrier_score`: домножить бинаризованные точки на несущую, вычесть фоновую фазу
  (посчитанную по рамке кадра), взять box-mean. **Результат**: карта `ghost_coarse.png` уже
  **читается** — `SM4RT3R / TH4N AI`. Гипотеза подтвердилась и объяснила, почему даунскейл «намекал»:
  усреднение по грубому масштабу чуть-чуть по-разному гасит точки с разной фазой ячейки.

- **Гипотеза (вторая копия атласа).** Фазовая карта размыта (box-mean по радиусу 24/9). Если Ghost
  Font ещё и **дублирует** область букв вторым, сдвинутым наложением одного и того же случайного
  атласа точек (типичный приём для повышения контраста «на глаз»), то её найдёт FFT-автокорреляция
  кадра с самим собой.
  **Проверка** — `find_vertical_shift`: по X сдвиг уже известен из структуры атласа
  (`SIGNAL_X_OFFSET = 294`, `ATLAS_WIDTH = 1296`), по Y — берём `argmax` круговой корреляции столбцов
  через FFT. **Результат**: чёткий пик `shift = 706/720` — вторая копия действительно найдена, и
  локальное точное совпадение (`equality`) даёт резкую, но шумную карту букв.

- **Финальный шаг.** Ни один сигнал по отдельности не чист: фаза — устойчивая, но размытая;
  наложение — резкое, но шумное. **Идея**: перемножить их — резкость останется только там, где оба
  метода согласны, что там буквы.

## 4. Уязвимость

Ghost Font кодирует текст **не в цвете и не в яркости**, а двумя привязанными к области букв
геометрическими свойствами одного и того же поля точек одновременно:

1. **Фаза 6-пиксельной решётки точек** — ячейки фона и ячейки под буквами отличаются фазовым
   сдвигом ячейки по вертикали. Это детерминированная периодическая метка, которую ловит
   согласованный фильтр на несущей `exp(-2πi·y/6)`.
2. **Самоналожение (overlay) сдвинутой копии атласа** — область букв дублирует тот же «случайный»
   атлас точек второй копией со сдвигом `(Δx=294, Δy=706)`. Совпадение двух копий видно через
   автокорреляцию (FFT) внутри одного кадра.

Ни то, ни другое не требует второго кадра анимации — оба сигнала лежат уже в единственном
скриншоте, надо лишь применить правильный (частотный/корреляционный) фильтр вместо взгляда «в лоб».

## 5. Эксплойт по шагам

Всё воспроизводит `decode_ghost.py`:

1. **`inspect_png`** — парсинг PNG-чанков + CRC + проверка хвоста после `IEND` → подтверждает
   отсутствие байтового стего.
2. **`normalize_canvas`** — убирает хром браузера вокруг холста и пересемплирует скриншот обратно
   в исходное разрешение `1280×720`, привязываясь к сетке `CELL_SIZE=6`, чтобы дальнейшая фаза не
   «плыла».
3. **`carrier_score`** — бинаризует точки, домножает на несущую `exp(-2πi·y/6)`, вычитает фоновую
   фазу (по рамке кадра шириной 40 px) и берёт box-mean (радиусы 24 и 9) → грубая, но уже читаемая
   маска текста.
4. **`find_vertical_shift`** — ищет вторую копию атласа круговой FFT-корреляцией по Y (X-сдвиг
   `294` px известен из структуры атласа).
5. **`recover_visual`** — считает локальное точное совпадение наложенных копий (резко, но шумно),
   перемножает с грубой фазовой картой (`rendered *= coarse-маска`) → чистый текст только там, где
   оба сигнала согласны.
6. **`save_cropped_visual`** — обрезает результат по области текста (`coarse > 0.06`) и сохраняет
   `ghost_decoded.png`.

```bash
uv run task2/decode_ghost.py ghost_screenshot.png -o ghost_decoded.png
# -> маска с текстом: SM4RT3R / TH4N AI
```

Чтение результата: `SM4RT3R` (верхняя строка) + `TH4N AI` (нижняя) → «smarter than AI» лит-спиком
(A→4, E→3). Служебный водяной знак «WRITTEN IN GHOST FONT» на этом кадре ни одним методом не
проявился — он в другом кадре/слое анимации и к флагу не относится.

## 7. Выводы

1. **Сначала отсекай дешёвые гипотезы.** Разбор PNG-чанков за секунду доказал, что секрет
   визуальный, и сэкономил время на `strings`/LSB/каналах.
2. **«Скриншот вместо видео» — подсказка к методу, а не к содержанию.** Анимация прячет текст во
   временну́ю когерентность; на одном кадре тот же приём переносится в пространство — через
   периодичность сетки и автокорреляцию кадра с самим собой.
3. **Согласованный фильтр бьёт «на глаз».** Фазовый детектор на несущей `exp(-2πi·y/6)` вытаскивает
   регулярную метку решётки чисто, тогда как даунскейл/карты плотности дают лишь грязный намёк.
4. **Комбинирование независимых сигналов даёт чистый результат.** Устойчивый-но-размытый (фаза) ×
   резкий-но-шумный (overlay) → читаемые буквы там, где методы согласуются.
