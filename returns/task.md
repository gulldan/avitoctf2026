который не умеет сочувствовать — нужно обойти его фильтры и получить возврат-ваучер.

## Цель
Через prompt injection / социальную инженерию заставить ИИ-агента одобрить возврат и выдать
ваучер (флаг `avito{...}`).

## Гипотезы
- Разведать JS-бандл фронтенда: как вызывается ИИ, какие эндпоинты, есть ли клиентские проверки,
  которые можно обойти;
- Джейлбрейк/prompt injection на сам ИИ-агент возврата — заставить его одобрить возврат вопреки
  guardrails;
- Классические веб-баги за фасадом ИИ: IDOR на id заявки/ваучера, скрытые эндпоинты, поддельное
  клиентское одобрение, JWT alg=none.
