# Task19 — МёдХантер: золотая звезда «Рекомендованный кандидат»

**Avito CTF 2026 · web (продолжение HRPortal)**

## Легенда
Тот же портал `https://hrportal-aoa51cvc.avitoctf.ru/`. Особенно ценятся кандидаты с **редким опытом**. Некоторые резюме получают **золотую звезду «Рекомендованный кандидат»**, хотя в интерфейсе такой настройки нет. Задача — понять, **какой опыт работы** нужно иметь, чтобы получить золотую отметку.

## Цель
Разобраться в серверной логике присвоения флага «Рекомендованный»: какие поля резюме/опыта (компания? должность? навык? годы? редкое значение?) триггерят золотую звезду. Создать резюме с нужным опытом → получить золотую отметку → флаг `avito{...}`.

## Гипотезы
- бэкенд помечает «recommended» по конкретному значению опыта (магическая компания/навык/тайтл), которого нет в UI-выпадашках;
- скрытое/недокументированное поле в API создания резюме; скоринг по редкому опыту;
- поищи в JS-бандле/ответах API логику присвоения звезды, список «редких» значений, эндпоинт резюме.
