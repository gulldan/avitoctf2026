# Brainwash

**Avito CTF 2026 · web / AimQL RCE**

## Условие

Медоед заметил, что его голова подозрительно пустеет: его мозги промывают в секретной
корпорации. Он вышел на их экспериментальную лабораторию. Чтобы победить, нужно узнать
все её секреты — «пошарьтесь хорошенько в их файлах».

Цель этапа — получить удалённое выполнение команд в персональном экземпляре лаборатории
и прочитать флаг из `/flag.txt`. Лончер и адрес экземпляра были динамическими во время CTF.

## Решение

Мишень работает на Aim 3.29.1. В AimQL уязвимость CVE-2025-5321 даёт выполнение команд,
но выражение вычисляется только при переборе существующего Run. Пустой репозиторий сначала
нужно засидировать через незащищённый remote-tracking сервер Aim, опубликованный не на
стандартном порту 53800, а на Kubernetes NodePort 30800.

Полный путь выглядит так:

1. создать ровно один Run через `aim://HOST:30800`;
2. передать AimQL-гаджет в `/api/runs/search/run`;
3. сохранить вывод команды в параметре созданного Run и прочитать его через обычный API;
4. извлечь `avito{...}` из `/flag.txt`.

Технический разбор этого этапа находится в
[Brainwash, часть 1](brainwash_writeup.md). Следующие этапы описаны отдельно в
[Brainwash, часть 2](../brainwash2/brainwash2_writeup.md) и
[Brainwash, часть 3](../brainwash3/brainwash3_writeup.md).

## Воспроизведение

Из корня репозитория:

```bash
uv sync --locked
uv run python brainwash/pwn_brainwash.py --self-test
uv run python brainwash/pwn_brainwash.py HOST
```

По умолчанию солвер использует web-интерфейс на `http://HOST` и tracking-сервер на
`HOST:30800`. Для другой топологии предусмотрены `--web-url`, `--tracking-host` и
`--tracking-port`.

Флаг: `avito{3Xperim3n7s_aR3_unREL1aBl3_BU7_rcE_N3V3R_liEs}`.
