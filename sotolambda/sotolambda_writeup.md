# СотоLambda

**Флаг:** `avito{Ea5Y_fIL3_DE5CrIP70R_l3ak}`

Привилегированный обработчик открывает `/etc/shadow` при проверке пароля.
Таймаут обходит закрытие файла, а отсутствие `O_CLOEXEC` оставляет дескриптор
загруженной программе. Через него читается хэш root и подбирается пароль.

## Утечка дескриптора

При `SIGALRM` обработчик вызывает `siglongjmp`, минуя обычную очистку. Открытые
дескрипторы накапливаются в долгоживущем процессе. Следующие дочерние процессы
наследуют их через `fork` и `execv`, даже после сброса UID.

Для запуска команд используется 159-байтный ELF с `execve("/bin/sh")`. Серия примерно
из 50 запросов `/api/invoke` под `runner / runner` с `stdin="sleep 3\n"` и
`timeout_ms=1` создаёт утечки. Все запросы должны попасть в один обработчик.

Превышать лимит дескрипторов нельзя: отдельная ошибка после неудачного `popen`
перезапускает процесс и теряет накопленное состояние.

## Чтение и подбор пароля

Следующий обычный запуск перебирает дескрипторы `3..200`. Perl открывает их через
`<&=`, не обращаясь к `/etc/shadow` повторно, сбрасывает смещение и читает содержимое.
Проверка прав уже была пройдена root-процессом при первоначальном открытии.

Запись root содержит DES-crypt хэш `azMuiLc/ZPwrM` с солью `az`. Словарный подбор
даёт пароль `mole`. Вызов `/api/invoke` с этими реквизитами запускает тот же ELF
с UID 0; команда `cat /root/flag.txt` возвращает флаг.

## Запуск

Нужен работающий Linux-экземпляр:

```bash
uv run python sotolambda/solve_sotolambda.py --base https://elflambda-<id>.avitoctf.ru
uv run python sotolambda/solve_sotolambda.py --self-test
```

[solve_sotolambda.py](solve_sotolambda.py) создаёт ELF через [mkelf.py](mkelf.py),
загружает его, вызывает таймауты, читает дескриптор и проверяет пароль по встроенному
словарю или `--wordlist`. Самотест проверяет ELF и DES-crypt на локальной фикстуре.
Бинарник `sandbox_worker.elf` не включён в Git.

Исправление — открывать секретные файлы с `O_CLOEXEC`, закрывать их на всех путях
завершения и не использовать `longjmp` так, чтобы он пропускал освобождение ресурсов.
