# SmartHive

Есть доступ обычного пользователя к системе умного улья, но его роли недостаточно,
чтобы открыть летковые ворота. Нужно получить управление воротами.

Параметры экземпляра во время CTF:

```text
launcher: https://smarthive-vzzgazuy.avitoctf.ru/
username: bee4
password: MusicIsLife123
```

Сервис написан на Spring Boot. Полученные исходники `ru.avito.iot.hivehub`
не включены в Git. [Решение](smarthive_writeup.md).
