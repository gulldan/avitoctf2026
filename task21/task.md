# Task21 — МёдХантер 3: мастер-секрет подписи резюме

**Avito CTF 2026 · web / crypto (продолжение HRPortal)**

## Легенда
Тот же портал `https://hrportal-aoa51cvc.avitoctf.ru/`. Каждый выпущенный PDF получает **уникальный идентификатор и код проверки** — по нему работодатели отличают документ МёдХантера от подделки. Задача — **достать главный секрет, которым подписываются резюме**, чтобы получить возможность подписывать ЛЮБЫЕ документы.

## Цель
Восстановить секретный ключ подписи (код проверки PDF = подпись/HMAC/JWT/подобное) → подделать валидную подпись для произвольного документа → флаг `avito{...}`.

## Гипотезы
- код проверки = HMAC(secret, id/содержимое) со **слабым секретом** → брутфорс (hashcat/john по id↔code парам);
- JWT с `alg=none`/слабым ключом; предсказуемый/утёкший ключ; length-extension (если голый `md5(secret‖msg)`);
- утечка секрета в env/конфиге/бандле; ключ выводится из id (детерминирован);
- собрать НЕСКОЛЬКО пар (id, verification-code) через генерацию PDF, восстановить схему и ключ, затем подписать свой документ.

## Зависимость
Генерация PDF за invite-кодом закрытой беты (см. МёдХантер 2 / task18). Возможно, сначала нужен invite — добудь его или переиспользуй, затем восстанавливай секрет подписи.
