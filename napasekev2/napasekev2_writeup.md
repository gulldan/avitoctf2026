# НаПасеке v2.0

**Флаг:** `avito{PCheLoV_V3rNUl_sTenu_no_EgO_z4meDliLi}`

Во второй версии индекс XMSS обновляется, но лишь после отправки подписи клиенту.
Если остановить запись в сокет до этого момента, можно получить часть подписи и
сохранить прежний индекс. Двух подписей под одним индексом хватает для подделки токена.

## Почему обычная гонка не подходит

Индекс находится в `MAP_SHARED`, доступном дочерним процессам. Если два процесса
используют старое значение и оба доходят до обновления, проверка завершает всю группу.
После перезапуска ключ меняется и собранные подписи теряют смысл.

У процесса регистрации остаётся активным `alarm(20)`. Маленькое окно приёма TCP и
заранее заполненный буфер блокируют `write_all()` посреди выдачи токена. `SIGALRM`
завершает только этот процесс; до обновления общего индекса он не доходит.

## Сбор подписи

Скрипт подбирает число предварительных команд `K`, чтобы остановить вывод в окне
от 616 до 3399 hex-символов. Этого хватает для первых 308 байт:

```text
idx: 4 | R: 16 | wots0: 288
```

Далее обычная регистрация под тем же индексом возвращает полную подпись и штатно
увеличивает индекс. Её хвост — путь аутентификации и верхние слои — подходит и к
частичной подписи. Перед объединением скрипт проверяет совпадение `idx` и `R`.

## Подделка токена

Две подписи дают по два наблюдения каждой WOTS+-цепочки. Для цели `kopatych`
перебирается поле `R*`, пока все 18 цифр её хэша и контрольной суммы не окажутся
не меньше минимальных наблюдённых цифр. Затем цепочки продолжаются вперёд, как в
[первой части](../napaseke/napaseke_writeup.md).

Полученный токен отправляется команде `L`, после чего `P` возвращает запись VIP
с флагом. Перебор `R*` локальный; дополнительных подписей сервера он не требует.

## Запуск

Нужны Linux-клиент и действующий код приглашения: минимальный эффективный `SO_RCVBUF`
на других ОС может не позволить остановить отправку в нужном месте.

```bash
NAPASEKE_INVITE='...' uv run python napasekev2/solve/solve_seqstall.py \
  --go --port 32012 --target kopatych
```

Хост передаётся через `--host`. Без `--go` скрипт не подключается.
Локальная проверка создаёт две синтетические подписи с повторным индексом,
подделывает подпись `kopatych` и полностью проверяет её:

```bash
uv run python napasekev2/solve/selftest.py
```

резервировать индекс до подписания и отправки, чтобы обрыв соединения или завершение
процесса не возвращали его в доступное состояние.
