# МёдХантер / HRPortal

**Avito CTF 2026 · web**

## Легенда
МёдХантер — портал вакансий Медоедска: медоеды публикуют резюме и откликаются на вакансии, компании ищут когтистых сотрудников.

Без **PDF-версии** резюме не рассмотрит ни одна солидная компания. Функция генерации PDF пока доступна только участникам **закрытого тестирования** — надо **раздобыть действующий код приглашения (invite)**.

## Цель
`https://hrportal-aoa51cvc.avitoctf.ru/`

Шаг 1 — получить валидный invite-код для закрытой PDF-генерации.
Шаг 2 (вероятно) — эксплуатировать саму PDF-генерацию (HTML→PDF рендерер: wkhtmltopdf/puppeteer/headless Chrome) → SSRF/LFI/чтение внутренних файлов → флаг `avito{...}`.

## Гипотезы
- invite: утечка в JS-бандле/ответах API, предсказуемый/угадываемый формат, IDOR, mass-assignment (`beta=true`/`role`), эндпоинт, выдающий код;
- PDF: SSRF (file://, http://169.254.169.254, внутренние сервисы), LFI, `<iframe>`/`<img>`/JS в рендерере, чтение `/etc/passwd`/конфигов/флага.
