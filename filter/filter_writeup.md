# Медофильтр

**Флаг:** `avito{ge7_in_Queu3_F0r_h0N3y!}`

DPI-процесс `hlp` блокирует HTTP-ответы, содержащие `avito{`. Ошибка разбора HTTP
позволяет завершить этот процесс, а правило NFQUEUE с `--queue-bypass` пропускает
пакеты, пока обработчик отсутствует.

## Как вызвать сбой

Сервис `cdn` отражает тело запроса к `/ping`. Большой ответ передаётся частями.
В `responce.Add` буфер ошибочно сбрасывается после порога 3072 байта, и разбор
продолжается с места внутри управляемого тела ответа.

Тело заполняется повторами 41-байтной строки:

```text
HTTP/1.1 200 OK\r\nContent-Length: 0\r\n\r\nZ\r\n
```

После сброса буфера парсер может принять её за отдельный ответ. Следующая строка `Z`
попадает в `TrailerNonChanked`, где выполняется:

```go
nameAndValue := bytes.SplitN(line, []byte(":"), 2)
trailer.Add(string(nameAndValue[0]), string(nameAndValue[1]))
```

В `Z` нет двоеточия, поэтому обращение к элементу `[1]` вызывает panic. Скрипт
отправляет по 1000 повторов и перебирает начальный отступ `0..40`, чтобы совместить
начало фрагмента с границей разбора.

## Получение флага

Параллельно выполняются запросы `/static/honey.txt`. Между падением `hlp` и его
перезапуском нет обработчика NFQUEUE, поэтому `--queue-bypass` выпускает ответ с флагом.

Серия быстрых сбоев также может исчерпать `startretries=3` до истечения `startsecs=1`:
Supervisor оставит процесс в `FATAL`. Для атаки достаточно короткого окна между
перезапусками. Само получение флага не доказывает переход в `FATAL`; это видно только
по журналу Supervisor.

## Запуск

Нужен работающий экземпляр Медофильтра:

```bash
uv run python filter/solve_filter.py https://filter-srv-ow2wt9j6.avitoctf.ru
```

[solve_filter.py](solve_filter.py) ограничивает число запросов и время работы,
чтобы не исчерпать память контейнера. Исходный архив `filter_74031b7.zip` нужен для
локального анализа парсера, но не включён в Git. Сохранённый флаг — [FLAG.txt](FLAG.txt).

Этот же скрипт решает [Медофильтр 2](../filter2/filter2_writeup.md).
Исправление — проверять формат строки до индексации и блокировать трафик при
недоступности фильтра.

Источники: [документации Supervisor](https://supervisord.org/subprocess.html#process-states).
