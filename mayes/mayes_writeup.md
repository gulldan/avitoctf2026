# Майя / Майес

**Флаг:** `avito{M4Y35_is_GO0d_BuT_a3S_IS_Bet73r}`

Mayes шифрует 16-байтный блок как четыре независимых слова по четыре байта.
В каждом слове есть подстановка байтов и обратимое аффинное преобразование по модулю
256. Параметры постоянны; для восстановления ключа сессии хватает шифрования нулевого блока.

## Модель шифра

Изменение одного входного байта затрагивает только соответствующее 32-битное слово.
Перебор значений байта даёт число различных выходов, равное степени двойки. Порядки
наблюдаемых перестановок — 128 и 16, что указывает на сложение по модулю 256, а не XOR.

Для каждого слова:

```text
s_i = S(p_i XOR k_i)
c_j = (sum_i M[j][i] * s_i + d_j) mod 256
```

`S` — перестановка байтов, `M` — обратимая матрица 4×4 над `Z/256Z`, `d` — константа.
Для коэффициента матрицы число выходов равно `2^(8-v2(M[j][i]))`: нечётный коэффициент
даёт 256 значений, кратный 16 — только 16.

Параметры восстановлены через отладочный оракул и сохранены в
[mayes_spec.json](mayes_spec.json): `M`, `M^-1`, `d`, прямые и обратные таблицы для
четырёх слов. Скрипт повторного восстановления спецификации в Git не включён.

## Восстановление ключа

При неверном ответе на запрос входа сервер возвращает его шифрование под текущим
ключом. Отправляем нулевой блок и получаем `E_K(0)`:

```text
E_K(0) = M * S(K) + d mod 256
K = S^-1(M^-1 * (E_K(0) - d))
P = K XOR S^-1(M^-1 * (C - d))
```

После неудачной попытки сервер присылает новый запрос. Расшифровывать нужно именно
его, а не предыдущий. Перед отправкой скрипт проверяет обе пары обратным шифрованием.

## Запуск

Нужен TCP-сервис с параметрами из сохранённой спецификации:

```bash
uv run python mayes/solve.py
```

[solve.py](solve.py) проходит начальную проверку кодом `v3FpEne80zLFyP1rOfj5rQ`,
выбирает `login`, получает `E_K(0)` и отправляет расшифрованный ответ второй попыткой.
Адрес сервиса указан в [task.md](task.md) и константах скрипта.

Отдельного `--self-test` нет: обычный запуск подключается к сети. Локальная модель
позволяет проверить алгебру, но не подтверждает доступность сервиса.
